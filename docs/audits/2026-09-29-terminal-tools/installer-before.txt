==> Waiting for the dashboard to answer
  ✓ backend is healthy

The dashboard is running.

  Reach it over an SSH tunnel. From your laptop:

    ssh -N -L 8443:localhost:8443 operator@TEST_SERVER

  Then open http://localhost:8443 while that stays open.

  Served over plain HTTP on loopback. That is not a downgrade: the ssh
  tunnel is already encrypted and authenticated, and browsers treat
  http://localhost as a secure origin — so there is no warning to click
  through and no certificate to explain.

  Useful from here:
    docker compose logs -f backend    # what the server is doing
    docker compose restart            # after editing .env by hand
    docker compose down               # stop it

  Ports, address, certificate and two-factor are all editable from the
  dashboard itself, under Operations → Dashboard → Configuration. It
  restarts into a change and puts the old one back if it does not come up.
