# Distributions scripts/verify-distros/run.sh installs the dashboard on.
#
#   name | image | package family
#
# name is what the result is filed under; image is the release's official
# container image, which run.sh turns into a booting systemd machine with only
# what a minimal install of it has (systemd, D-Bus, git to clone with, the
# certificate store); family says how to add those. prepare/<name>.sh, where
# there is one, runs after, for an image that is not yet the release it is named
# for. Images are x86_64.
